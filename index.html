APUNTADORES EN C++

Dirección, acceso y vida útil

Un apuntador T* puede señalar un objeto de tipo T, ser nulo (nullptr) o cambiar de destino. Desreferenciarlo con *p permite leer o modificar ese objeto; solo es válido si apunta a un objeto vivo y accesible.

¿Para qué sirven?
  • Opcionalidad: expresar «puede no haber objeto» con nullptr.
  • Polimorfismo: un Base* puede referir a una instancia derivada y llamar métodos virtual.
  • Propiedad: std::unique_ptr y std::shared_ptr gestionan vida útil con RAII.
  • Interoperabilidad: conectar APIs, estructuras de datos y recursos existentes.

Regla práctica: referencias para parámetros obligatorios; apuntadores crudos generalmente no propietarios; apuntadores inteligentes cuando se transfiere o comparte propiedad.

Los trazos esenciales para no perder el hilo.

01　struct agrupa datos públicos　＋
struct Punto {
  double x{}, y{};
};
Punto origen{0.0, 0.0};
En C++, struct y class comparten capacidades; cambia el acceso predeterminado.


02　class protege invariantes　＋
class Cuenta {
public:
  void depositar(double monto);
private:
  double saldo_{};
};
private oculta la representación; la interfaz pública controla el estado.


03　Herencia relación «es un»　＋
class Circulo : public Figura {
public:
  double area() const override;
};
Usa virtual en la base y override al redefinir una operación.


04　Acceso class vs struct　＋
struct S { int dato; }; // public
class C { int dato; };  // private
Escribe public: o private: para dejar clara la intención.


05　Constructor inicializa estado válido　＋
Producto(std::string nombre, double precio)
  : nombre_(std::move(nombre)), precio_(precio) {}
La lista de inicialización configura miembros antes de entrar al cuerpo.


06　Polimorfismo una interfaz, varias formas　＋
virtual ~Figura() = default;
virtual double area() const = 0;
Un destructor virtual permite destruir objetos derivados mediante un puntero a la base.
07　Apuntadores dirección, acceso y propiedad　＋
int valor = 42;
int* p = &valor;  // guarda la dirección
*p = 7;           // modifica el objeto

std::unique_ptr<Figura> f =
    std::make_unique<Circulo>(2.0);
T* puede ser nulo y no implica propiedad. Para propiedad dinámica, prefiere std::unique_ptr o std::shared_ptr; desreferencia únicamente un apuntador válido.
